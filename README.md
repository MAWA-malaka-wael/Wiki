# Wiki Encyclopedia

A Django-based encyclopedia web application built as part of Harvard's CS50 Web Programming with Python and JavaScript course.

The application allows users to browse, search, create, and edit encyclopedia entries written in Markdown.

## Features

- Browse all encyclopedia entries
- View individual entries
- Search for entries by title
- Create new encyclopedia entries
- Edit existing entries
- Navigate to a random entry
- Convert Markdown content into HTML

## Technologies Used

- Python
- Django
- HTML
- CSS
- Markdown2

## How to Run Locally

1. Clone the repository:

```bash
git clone https://github.com/MAWA-malaka-wael/Wiki.git
Navigate to the project directory:
cd Wiki
Install the required dependencies:
pip install -r requirements.txt
Run the development server:
python manage.py runserver
Open the application in your browser:
http://127.0.0.1:8000/
